Cần paginate cho bookmark, post, follower và following.

Xây dựng thuật toán để hiển thị gợi ý ngữ pháp cho người dùng etsubi.

Khi phiên dịch thì sẽ có một thanh gạch chân trắng phía bên dưới, khi hover thì sẽ hiển thị các chỗ cần sửa theo 3 tiêu chí:
- Đỏ: Cần sửa vì lỗi nghiêm trọng 
- Vàng: Mức độ nghiêm trọng thấp hơn, nên sửa 
- Xanh lá: Có thể cải thiện

Khi phiên dịch thì trình duyệt sẽ gửi lại toàn bộ ngữ cảnh để phía server thông qua api để xử lý.



Map thì cũng sẽ có cơ chế xử lý riêng, live view thì có thể sẽ cân nhắc.
